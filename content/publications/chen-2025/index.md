summary: This work introduces OptiChat, a natural language dialogue system that enables practitioners to interact with, analyze, and understand optimization models using large language models and optimization tools.
abstract: OptiChat is an LLM-assisted dialogue system designed to bridge the gap between optimization models and practitioners without optimization expertise. The system combines a multi-agent framework with optimization solvers, predefined functions, and code generation to interpret model formulations, diagnose infeasibility, retrieve information, analyze sensitivity, evaluate model modifications, and provide counterfactual explanations.
